# tarilka0gg.github.io

Personal site: <https://tarilka0gg.github.io>

Plain HTML and CSS with one small script for the background waves (canvas, pauses in hidden tabs, still for reduced motion). No build step: GitHub Pages serves this folder as is.

- `index.html`, `projects/`, `about/` - the three pages
- `assets/site.css`, `assets/waves.js`, `assets/favicon.svg`

Preview locally: `python3 -m http.server` and open <http://127.0.0.1:8000>.
