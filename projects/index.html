Simple Linux

A small Gentoo-based live system with its own installer.

  • Online and offline ISOs (a minimal text image and a GUI image), plus the stage3 they install from.
  • The GUI image boots into niri with the Noctalia bar and dock, Ghostty, fish, Thunar, Zen Browser and Portage Store.
  • A kernel matched to the hardware, from kernel-matrix, and signed binary packages from its own binhost.
  • 43 releases between October 5 and October 28, 2026.
  • GPL-2.0
  • Gentoo · OpenRC · Limine

    Installer

    Text and GTK4 frontends over one Rust core.

    • The text installer, the GTK4/libadwaita wizard and --headless run the same 16 phases, from partitioning to the bootloader.
    • A journal lets a failed install resume without redoing destructive steps.
    • Reads the CPU, GPU and laptop/desktop type and deploys a prebuilt kernel for it, falling back step by step to a generic x86-64 build. Nothing is compiled on the machine.
    • Can install into free space next to Windows or other Linux systems, never formats an existing EFI partition, and adds them to the Limine menu.
    • About ten minutes package by package, under two minutes for the default desktop (QEMU with KVM).
    • GPL-2.0-or-later
    • Rust · GTK4 · ratatui

      Portage Store

      An app store for Gentoo Portage, with a CLI on the same core.

      • Search, install and update packages, with builds streaming live in a job queue.
      • Points out what Gentoo expects you to remember: security advisories, unread news, pending config updates, a stale tree, orphaned packages.
      • USE flags in the UI, starter bundles on first run.
      • The privilege model is documented up front, not hidden.
      • GPL-2.0
      • Rust · GTK4 · libadwaita

        ustan

        A Windows-style app installer for Linux: open a package, press Install.

        • .deb, .rpm, Arch packages, AppImage, snap, Flatpak, .exe/.msi, archives, .jar and bare binaries.
        • Everything goes into your home directory. No root, a menu entry and an icon, and a clean uninstall.
        • Distro packages run with their files overlaid on /usr through bubblewrap. Snaps run without snapd, verified and sandboxed. Windows programs get a Wine prefix each.
        • Multi-gigabyte .xz archives are decoded on several threads (Zig over liblzma), and downloads are checked against published checksums.
        • GPL-2.0
        • Rust · Zig · GTK4

          tui-shim

          Terminal apps that behave like desktop apps.

          • micro and nvim in Ghostty get a small folder badge. Click it or press F9 for a native file picker, and the file opens in the same window.
          • Search ignores case, ranks exact and prefix matches first and looks into sub-folders.
          • A launcher entry, an icon and its own window class for each terminal app, plus palette theming.
          • GPL-3.0
          • Rust · GTK4 · layer-shell

            Ring-2Zero

            Your Wayland desktop in a browser tab, over WebRTC.

            • Zero-copy capture through wlr-screencopy DMA-BUF, with a PipeWire portal fallback for GNOME and KDE.
            • The screen is cut into tiles and hashed in two stages. On a real desktop 85 to 99 % of tiles are skipped and only changed ones are sent, as WebP.
            • Tiles that change often, change fast or sit near the centre go first.
            • The browser client is built into the binary: run one program, open a URL. Remote mouse and keyboard are optional and off by default.
            • MIT
            • Rust · WebRTC · Wayland
            • since Jul 2026

              Distribution parts

              • kernel-matrixKernel · Shell

                Kernel configs as a matrix: 19 CPUs × 7 GPUs × 5 platforms × 11 embedded controllers × 4 modems, 7,614 targets. Kconfig fragments are merged on a fixed seed, built in batches through one make jobserver, and checked by a script that catches options Kconfig silently drops.

              • simple-linux-binhostPackages

                Signed binary packages that Gentoo's own binhost lacks: niri, Noctalia, Ghostty, and the packages the installer builds with different USE flags. Also hosts the prebuilt kernels.

              • simple-linux-configsDesktop

                Clean default configs for niri, Hyprland, Sway, Scroll, Labwc, MangoWC, Triad and dwl, each paired with Noctalia as the bar.

              • simple-localeRust · JS

                One language setting for every Simple Linux program: a shared locale.toml next to the system locale, English by default. A Rust crate with a JavaScript twin.

              Laptop lab

              • system-labNotes · Data

                Everything done to the machine itself: BIOS unlock, undervolting through the OC mailbox, power limits, fans, and Clang + AutoFDO kernel builds. A 29-session journal, test logs and the CSVs behind each conclusion, in a SQLite data stack.

              • power-scriptsShell · OpenRC

                Deep-idle power management for a gaming laptop: an idle toggle, a sustained-turbo fan daemon, an AC/battery switch, and EC settings re-applied after boot and resume.

              • gpu-undervoltShell · NVIDIA

                A clock offset for an NVIDIA laptop GPU (core +125, memory +250) applied at boot through a throwaway headless Xorg, so Coolbits works on a Wayland-only system.

              Other

                A Rust rewrite of TelegramHelper: a userbot and a control bot on grammers, a localhost dashboard, and Zig SIMD helpers.
