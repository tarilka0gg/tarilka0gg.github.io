Projects

A small Gentoo-based distribution and the tools it needed. Every project says in its README what was tested and what was not.

Simple Linux

  • Simple LinuxDistribution

    A small Gentoo-based live system: online and offline ISOs, a kernel matched to your hardware, niri and Noctalia.

  • InstallerRust · GTK4

    Text and GTK4 frontends over one Rust core. Installs next to other systems, resumes after a failure, boots with Limine.

  • Portage StoreRust · GTK4

    An app store for Gentoo Portage: browse, search, USE flags, updates, and a CLI on the same core.

  • BinhostPackages

    Signed binary packages that Gentoo's own binhost lacks: niri, Noctalia, ghostty.

  • kernel-matrixKernel

    Kernel configs as a matrix of CPU, GPU, platform, EC and modem, merged from Kconfig fragments and verified.

Desktop tools

  • ustanRust · GTK4

    A Windows-style app installer: .deb, .rpm, Arch packages, AppImage, snap, Flatpak, .exe. No root, clean uninstall.

  • tui-shimRust

    Terminal apps that behave like desktop apps: launchers, icons, palette theming and a file picker for editors.

  • Ring-2ZeroRust · WebRTC

    A Wayland screen streamer with tile-based diff encoding: your desktop in a browser tab.

  • ConfigsDesktop

    Clean default configs for niri, Hyprland, Sway, Labwc, MangoWC, dwl and more, paired with Noctalia.

Laptop lab

  • system-labNotes · Data

    BIOS unlock, undervolting, RAPL/EC turbo and Clang + AutoFDO kernel builds on an HP Victus 16, with the measurements.

  • power-scriptsShell

    Deep-idle power management for a gaming laptop on OpenRC and niri.

  • gpu-undervoltShell

    NVIDIA laptop GPU clock offsets at boot through a throwaway headless Xorg, on a Wayland-only system.

Upstream

  • unrootContributions

    Fixes for Daniel Robbins' Linux root filesystem tool: OCI layers, foreign-arch entry through QEMU, builds without LTO.

  • keychainContributions

    Fixes for the ssh-agent and gpg-agent manager.
